Web Browsers and Web Servers

A web browser is a software application used by users to access and display web pages. Examples include Chrome, Edge, Firefox and Safari.

A web server is a computer system or software that stores and delivers website resources to clients when requested.

Client-side vs Server-side Scripting

Client-side scripting is executed in the user's web browser, whereas server-side scripting is executed on the web server.

Client-side Scripting

💻
  • Runs in the web browser.
  • Used for interactive interfaces.
  • Can respond quickly to user actions.
  • JavaScript is commonly used.
VS

Server-side Scripting

🖥️
  • Runs on the web server.
  • Processes requests and data.
  • Can communicate with databases.
  • Examples include PHP, Python and Node.js.
