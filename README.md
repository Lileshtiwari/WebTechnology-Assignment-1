# Web Technology Assignment 1

This repository contains the complete implementation of **Web Technology Assignment 1**, covering fundamental web development concepts, HTML5 forms, CSS-based webpage design, and interactive JavaScript applications.

## 📚 Questions Covered

### Q1 – Web Concepts
Introduces fundamental concepts of web development, including how websites work and the role of HTML, CSS, JavaScript, browsers, servers, and HTTP in web applications.

### Q2 – Student Admission Form
A structured **Student Admission Form** developed using HTML5. It demonstrates different form elements, input fields, dropdowns, radio buttons, checkboxes, validation, and CSS styling.

### Q3 – Fashion Store
A **Fashion Store webpage** designed using HTML and CSS. It demonstrates webpage structure, product presentation, navigation, images, typography, layouts, and responsive styling.

### Q4 – Grade Calculator
An interactive **Grade Calculator** developed using JavaScript. It accepts marks, performs calculations, determines the appropriate grade, and dynamically displays the result using DOM manipulation.

### Q5 – Supermarket Billing System
An interactive **Supermarket Billing System** developed using JavaScript. It demonstrates arrays, objects, functions, and DOM manipulation. The system supports product selection, quantity management, automatic subtotal calculation, **10% discount**, GST calculation, payment handling, bill generation, and a supermarket-style printable receipt.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Navigate to the required question folder.
4. Open its `index.html` file.
5. Run the webpage using a browser or the Live Server extension in VS Code.
6. For JavaScript-based questions, make sure the corresponding `script.js` file is correctly linked to the HTML file.
